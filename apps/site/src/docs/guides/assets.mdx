Cobble UI does not contain or redistribute any Minecraft textures, sounds or fonts. Instead, the
visitor's browser downloads them straight from Mojang when the page loads:

- The version manifest and asset index come from `piston-meta.mojang.com`.
- The 26.3 client jar (≈41 MB) comes from `piston-data.mojang.com`. Its SHA-1 is checked against the
  value Mojang publishes, then only `assets/minecraft/textures/gui/` is kept, in Cache Storage. Later visits skip the download.
- Sounds and the title-screen panorama are loaded by `<audio>` and `<img>` elements directly from
  `resources.download.minecraft.net`.

You can point the loader somewhere else (for example your own proxy) with `mojangAssets()`:

```tsx
<CobbleProvider assets={mojangAssets({ version: '26.3', cache: true })}>…</CobbleProvider>
```

## Fonts

The `minecraft-ttf` fonts are generated from the game's bitmap font by their author. `npx cobble-ui fonts <dir>`
downloads them from that project's GitHub release.
